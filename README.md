# Investment Banking Trade Reconciliation Project

## Project Overview

This project demonstrates a simulated Investment Banking Trade Reconciliation process using Microsoft Excel.

The project compares internal trade records with counterparty trade records to identify mismatches, investigate trade breaks, and summarize reconciliation results through an Excel dashboard.

## Objectives

- Understand the investment banking trade lifecycle
- Compare internal and counterparty trade records
- Identify trade mismatches and trade breaks
- Perform trade reconciliation using Excel
- Create an exception report
- Build a reconciliation dashboard

## Tools & Skills Used

- Microsoft Excel
- XLOOKUP
- IF
- COUNTIFS
- SUMIFS
- Pivot Tables
- Conditional Formatting
- Sorting & Filtering
- Data Cleaning

## Project Components

### 1. Trade Register
Contains the internal trade records, including trade ID, security, asset type, Buy/Sell instruction, quantity, price, trade date, settlement date, and currency.

### 2. Counterparty Trades
Contains corresponding counterparty trade records used for comparison and reconciliation.

### 3. Trade Matching
Uses Excel formulas to compare internal and counterparty trade details and identify whether each field matches or has a break.

### 4. Exception Report
Summarizes identified trade breaks, including differences in quantity, price, trade date, settlement date, and Buy/Sell instructions.

### 5. Dashboard
Provides a summary of total trades, matched trades, trade breaks, match rate, asset types, and break categories.

## Key Result

The reconciliation analysis identified mismatches between internal and counterparty trade records and summarized the results using an Excel dashboard.

## Dataset

The dataset is simulated and was created specifically for educational and portfolio purposes. It does not contain real bank, client, or confidential trading data.
